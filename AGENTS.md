## Deployment

Deployment follows the same pattern as `gracht-app`.

The workflow in `.github/workflows/deploy.yml`:

1. Checks out this app repo.
2. Checks out `evgenyio/evgenyio.github.io` into `site/` using `SITE_DEPLOY_KEY`.
3. Copies this repo into `site/projects/luisterspoor/`.
4. Commits and pushes that folder.
5. GitHub Pages serves it at `https://evgeny.io/projects/luisterspoor/`.

Important workflow detail:

- The deploy step must exclude `.git`, `.github`, and `site`. It also excludes `*.md`, so these notes and the README stay off the site.
- If `site` is not excluded, the target checkout gets recursively copied into the deployed app.

The deploy key is attached to:

- target repo: `evgenyio/evgenyio.github.io`
- source repo secret: `Evgeny-/luisterspoor` → `SITE_DEPLOY_KEY`

To inspect deployment:


## PWA And Offline

The app is installable because it has:

- `manifest.webmanifest`
- app icons in `icons/`
- `service-worker.js`
- HTTPS hosting through GitHub Pages/custom domain

The service worker is generated by the packager and keeps two caches:

- `luisterspoor-shell-<hash>`: the page, `app/`, `icons/`, `manifest.webmanifest` and `tracks.json`. The hash covers their contents, so any interface change makes a new shell cache and the worker updates.
- `luisterspoor-media`: MP3s, JSON timing manifests and TXT phrase lists. `tracks.json` points at them with a content hash (`recall-all-mixed.mp3?v=…`), so a release that only changes the interface downloads no audio, and a rebuilt track gets a new URL. On activation, media no longer listed in `tracks.json` is dropped.

Updates: installing caches only the shell, so a release takes over within seconds. The page then asks the worker (`warm-media`) to download missing audio in the background, and every visit repeats that, so it resumes. When a new worker takes control, a page that already had one reloads itself, and if audio is playing it waits for a pause. The first worker (`luisterspoor-v1` to `v6` caches) knew none of this, so a worker that finds those caches deletes them and reloads the pages once.

It answers `Range` requests for cached audio by slicing the cached blob. Browsers request audio with `Range` headers, and without this, offline playback can fail or seek poorly.

Offline setup expectation:

- The user must open the app once while online and leave it open until the audio has downloaded (about 155 MB, all five tracks, in the background).
- After that, the app works offline from the installed PWA or browser cache, including seeking and switching tracks.

## Asset And GitHub Limits

Current deploy size is intentionally modest:

- deploy repo total: about 160 MB
- largest MP3: about 50 MB
- final tracks only: recall and Dutch-only mixes of the A2–B1 and A1–A2 phrases, and the A1–A2 irregular verbs

Do not add source-order tracks unless there is a strong reason. They doubled storage without adding much learning value.

GitHub hard-blocks files over 100 MB. Keep every individual MP3 below that limit.

Useful docs:

- https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github
- https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

GitHub Pages also has practical bandwidth limits. Large audio is acceptable here, but avoid many alternate renders unless needed.

The mixed order is deterministic:

## UI Notes

The player ("Stage") is dark and built around a lyrics-style stream: the current phrase is large in the middle, its words light up as they are spoken, neighbours are dimmed, and the stream follows playback until you scroll (then "Back to now" points up or down to the current phrase). Brand colours come from the icon: tulip orange `#ff7a2f` for the play button and highlights, deep Delft blue night `#0a0f1f` for the background. System fonts only, so the PWA works offline.

- The tracks are always visible: a library rail on the left at 960px and wider, a horizontal strip of set and mode chips above the stream on phones. Each shows how much of the track is listened.
- Speed opens a row of all speeds (0.75–1.5×); keyboard − and + step it. Space plays and pauses, ← → change the phrase.
- The lock screen (Media Session) shows the English phrase during the recall pause and the Dutch after it; ⏮ ⏭ move between phrases.
- Keep motion quiet: the playing track has a static mark, not an animated equalizer.
- A link to oefenschrift.nl sits at the bottom of the rail and at the end of the phone strip.

Always verify at desktop width and a phone viewport around `390x844`. `?muted` in the URL plays silently, which helps when testing.

## Common Gotchas

- Do not serve this app through `file://`; service workers and JSON/audio fetch behavior need HTTP(S).
- Do not put secrets into this repo. The deploy private key is only in the GitHub Actions secret.
- Icons come from `public/icons/` in the source workspace; see Icons above.
- If changing the packager, update `/Users/evgeny.nikiforov/Projects/dutch/scripts/build_deploy_package.py`, not only this repo.
- If changing deployed files directly in this repo, consider whether the packager will overwrite them later.
